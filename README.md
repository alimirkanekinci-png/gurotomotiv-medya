# Gür Otomotiv medya

gurotomotiv.com.tr sitesinin görselleri ve araç söküm videoları. jsDelivr üzerinden servis edilir:
`https://cdn.jsdelivr.net/gh/alimirkanekinci-png/gurotomotiv-medya@<sürüm>/<yol>`

- `img/` logolar, giriş görselleri, araç küçük resim şeritleri
- `arac/<id>-tel.mp4` söküm videosu, `arac/<id>-kare.webp` 16 karelik şerit, `arac/<id>.jpg` poster
